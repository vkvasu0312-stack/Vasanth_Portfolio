# Vasanth — Freelance Web Developer Portfolio

A responsive, modern portfolio website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — website content
- `style.css` — design and responsive layout
- `script.js` — mobile menu and current year

## Before publishing
Replace:
- `your.email@example.com`
- `919999999999` with your WhatsApp number
- LinkedIn and GitHub links
- Demo project descriptions/images with your real work

## Run locally
Open `index.html` in a browser.

## Deploy
This static site can be deployed to Vercel, Netlify, GitHub Pages or any normal web host.
